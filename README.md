## Featured project

### [SHIELD — Scam Awareness Workspace](https://rockstarani231-arch.github.io/shiny-umbrella/)

A browser-based project that helps people review common scam warning signs.

- **Messages and SMS:** local pattern checks for urgency, impersonation, and payment pressure.
- **Links:** local URL-structure checks, including onion and i2p addresses, without opening them.
- **India call screening:** Indian mobile-number checks against reports saved in the browser, plus a personal watchlist and links to official reporting resources.
- **File inspection:** local metadata and SHA-256 fingerprint calculation. This is not antivirus scanning.

[View the source code](https://github.com/rockstarani231-arch/shiny-umbrella)

SHIELD is a learning project. Its checks are guidance, not guarantees; it does not block calls or texts, and it does not use an AI service or live caller-reputation feed.
